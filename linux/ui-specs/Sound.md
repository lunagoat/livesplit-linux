# Sound Effects
Toolkit-free model: SoundSettings, with SoundData per EventType and SoundFileSettings / SoundVolumeSettings row models.

Tabs in order: **Sound Files**, **Volume Mixer** (scrollable).
Sound Files begins with “Drag and Drop Mode:” and mutually exclusive radios “Clear and Add Files” (IsClearAddDragDrop=true, default) and “Append Files” (false). Applied immediately to every file row.
Each event row, in enum order, has a label, read-only comma-separated path textbox (FilePathsText), “Browse...” and “Clear”. Browse replaces FilePaths with multiple selected files; filter “Audio Files|*.mp3;*.wav;*.aiff;*.wma|All Files|*.*”. Drop replaces or appends distinct paths using DropFiles. Clear assigns an empty list. Path tooltip on focus shows one path per line below the textbox; hide on blur. No tooltip title. Browsing/drop commits immediately; text is not editable.
Event labels in order: “Split:”, “Split (Ahead, Gaining Time):”, “Split (Ahead, Losing Time):”, “Split (Behind, Gaining Time):”, “Split (Behind, Losing Time):”, “Split (Best Segment):”, “Undo Split:”, “Skip Split:”, “Personal Best:”, “Not a Personal Best:”, “Reset:”, “Pause:”, “Resume:”, “Start Timer:”.
Volume Mixer begins with “Output Device:” dropdown (legacy OutputDevice index, previously NAudio product names), then “General Volume:” slider (GeneralVolume). Each event label above repeats with a Volume slider bound to its SoundData. All sliders 0–100 inclusive, step 1, ticks 10, default 100; tooltip is current integer value (no title), updated while scrolling. Immediate edits. No other enable/visibility dependencies.
Linux uses the audio server default output; IsOutputDeviceEnabled=false. Preserve OutputDevice XML for Windows compatibility; do not interpret Windows indices as Linux devices. Linux selects executable pw-play, paplay, mpv, ffplay in that order from PATH; missing backend is reported in logs. Volume is event volume multiplied by general volume. Each event cancels prior playback; disposal kills playback. Paths remain unchanged in XML and resolve through Core PathCompat at playback.
Legacy XML supports single text paths as well as nested path lists. Version 1.6; drag/drop mode is persisted. No hidden font/color settings.
