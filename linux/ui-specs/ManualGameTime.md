# Manual Game Time settings and input contract

Settings: one group “Game Time Input”, two mutually exclusive radio buttons: “Segment Times” → `UseSegmentTimes` (true by default), “Split Times” → `UseSplitTimes` (inverse). Immediate commits. No ranges, tooltips, tabs, or hidden settings. XML remains Version 1.4 / UseSegmentTimes; missing value retains legacy false fallback.

The old “Enter Game Time” auxiliary window contained one anchored textbox (260px wide, window 284×44). It is replaced by a drawing-based layout component, with no embedded toolkit control or IFormHost child control. Its row uses the layout's text font/color and shows “Enter Game Time: ” followed by `InputText`, or an invalid-time message through `InputError`. Natural size is 320×36; inactive rows show “Start the timer to enter game time”.

Host contract: focus this component on click/keyboard navigation and forward local text input to `AppendText(string)` and local key-down events to `HandleKeyDown(KeyEventArgs)` only while focused. This API deliberately does not subscribe to global keyboard events. Forward composed text (including punctuation and paste) as text, not key names. The drawn editor appends text and deletes from its end; it does not implement a caret or text selection. A host needing full text editing can assign InputText directly. Backspace deletes the last text element; Delete/Escape clear; Enter commits; handled commands set Handled and SuppressKeyPress. Host should request a frame after input; Update invalidates when text, validation, or phase changes. No extra Core API is required. InputText also supports direct assignment by an accessible host editor; all mutation occurs on the host UI thread.

On start clear input/errors, pause game time and initialize it to zero. Entry is accepted only while Running or Paused. Enter removes spaces, sums `+`-separated TimeSpanParser values, adds current game time for Segment Times (or uses absolute time for Split Times), sets game time and requests a split, then clears text. As in the legacy window, TimerModel advances a split only while Running; submitting while Paused updates the game time without advancing. Invalid input or overflowing sums keeps the text and exposes an error without changing time or splitting. Undo restores the prior split game time (zero at the first split); reset clears input. Dispose unsubscribes all timer events. The host owns focus/accessibility; no separate input window is opened.
