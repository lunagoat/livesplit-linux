# Counter settings

No tabs or tooltips. Labels are translation keys. Control order:
- “Background Color:” two swatches and drop-down (`GradientString`, options `GradientOptions`: Plain, Vertical, Horizontal). First swatch binds `BackgroundColor`, visible when `IsColor1Visible`; second binds `BackgroundSwatch2Color` (BackgroundColor in Plain, BackgroundColor2 otherwise).
- Group “Counter Colors”: “Override Layout Settings” checkbox → `OverrideTextColor`. “Text Color:” → `CounterTextColor` swatch; “Value Color:” → `CounterValueColor` swatch. Both labels and swatches enabled by `IsCounterColorEnabled`.
- Group “Counter”: “Counter Text:” textbox → `CounterText` (legacy commits on validation). “Initial Value:” integer → `InitialValue`, −2147483648..2147483647, step 1, zero decimals; changing it reinitializes the counter. “Increment Value:” integer → `Increment`, 0..2147483647, step 1, zero decimals; changing it updates increment without resetting the count. Numeric controls formerly committed on validation, with ValueChanged applying immediately.
- Nested group “Hotkeys”: “Increment Counter:” → `IncrementKey`; “Decrement Counter:” → `DecrementKey`; “Reset Counter:” → `ResetKey`, all hotkey capture fields. “Global Counter Hotkeys” checkbox → `GlobalHotkeysEnabled`. Otherwise keys operate only while host `IsActive`.
- On capture focus show “Set Hotkey...”; suppress ordinary text input. Capture key code + modifiers on key-down, modifier-only keys on key-up. Escape clears to null (“None”); leaving cancels and retains old value. Gamepad input can assign a button when supported by the backend. View displays KeyOrButton.ToString (legacy gamepad label drops final space-delimited suffix), then leaves capture focus. Setting a key re-registers this component's hook only. Do not clear the application's global hook. View owns capture lifecycle and font/color dialogs.

Defaults: Counter:, initial 0, increment 1; Add / Subtract / NumPad0; local keys; white text/value; transparent Plain background. Legacy `OverrideCounterFont` and `CounterFont` are read for font migration, neither shown nor written. Runtime `Hook` is read-only and owned/disposed by settings. All settings update immediately in the model; no persisted format change.
